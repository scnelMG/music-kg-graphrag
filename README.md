# Music Knowledge Graph & GraphRAG

> **보관용 · 중단된 개인 실험**

개인 음악 기록과 지식 그래프 추천을 연결하려 했던 실험 저장소입니다. 현재 개발과
포트폴리오 소개를 중단했으며, 공개 배포 서비스·완성된 GraphRAG 제품으로 보아서는
안 됩니다.

## 남아 있는 구현

- MusicBrainz 앨범 검색, Notion 기록 연동, Spring Boot·Next.js·Python 파이프라인 코드
- RDF/SPARQL 기반 개인 기록 투영과 추천 실험 코드
- 프론트엔드·백엔드·파이프라인의 회귀 테스트와 개발용 Docker Compose 설정

## 사용 전 확인

- 공개 배포 주소, 개인 Notion 연결, 추천 품질, 운영 안정성은 보장하지 않습니다.
- 실제 자격 증명과 개인 음악 기록은 저장소에 포함하지 않습니다.
- 문서와 설정 파일은 개발 당시의 기록이며, 현재 환경에서의 실행을 지원하지 않습니다.

## 이용 안내

이 저장소는 과거 실험 기록 열람을 위해 공개합니다. 코드·문서·이미지의 재사용, 수정, 배포는 사전 문의가 필요합니다.
